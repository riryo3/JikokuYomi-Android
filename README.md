# 時刻読み (Jikoku Yomi) for Android

**好きなキャラに、好きな言葉を、15分ごとに喋らせるアプリ。**
時刻を読む必要はありません。音声ファイルを置けば、その音声が決めた時刻に鳴ります。

Let your favorite character say anything you like, every 15 minutes. The app plays your own audio files at the times you choose. They don't have to say the time.

## ボイスパック(音声ファイル)

音声ファイルを入れたフォルダ、またはそのzipを、アプリの「フォルダから取り込む」「zipから取り込む」で選びます。
zipの中にフォルダがあっても読みます。zipの名前が、パックの名前になります。

### ファイル形式

`wav` / `mp3` / `m4a` / `aac` / `flac` / `ogg`

### ファイル名

| ファイル名 | 鳴る時刻 |
|---|---|
| `t0000` 〜 `t2345` | その時刻(15分ごと。例: `t0715.wav` は 7:15 に鳴る) |
| `m15` `m30` `m45` | 時を言わない設定のときの 15分・30分・45分 |

- 時刻の形は `tHHMM` です。`HH` は 00〜23、`MM` は 00・15・30・45。
- 全部そろえると、96ファイル + `m15` `m30` `m45` の 3ファイル = **99ファイル**です。
- 全部そろえなくても動きます。ファイルがない時刻は、端末の音声合成(TTS)が読みます。
- 拡張子の前の名前は、小文字にしてください(例: `t0715.wav`)。

```
my_pack/
├── t0000.wav
├── t0015.wav
├── ...
├── t2345.wav
├── m15.wav
├── m30.wav
└── m45.wav
```

### 複数パックをランダムに

パックを2つ以上入れたら、「誰に喋らせるか」で「ランダム(複数パック)」を選びます。
使うパックにチェックを入れます(「全部選ぶ」「全部外す」ボタンあり。全部オフなら全パック)。

- 順番は毎回ランダムですが、全パックが同じ回数ずつ選ばれます(シャッフル再生と同じ「袋方式」)。
- 全パックを使い切ったら、また最初から混ぜ直します。直後に、同じパックは続けて選びません。
- その時刻のファイルがないパックは、飛ばします。
- 時刻ごとの設定でも、「ランダム」を選べます。

## インストール

Android 8.0 以上。

1. [Releases](../../releases) の APK を端末に入れて、「提供元不明のアプリ」を許可してインストール
2. 通知を「許可」
3. アプリ内の「バッテリー最適化を無効化する」を押す(時刻どおりに鳴らすために必要)

自分でビルドする場合(JDK 17 と Android SDK が必要):

```bash
./gradlew assembleDebug
# app/build/outputs/apk/debug/app-debug.apk
```
