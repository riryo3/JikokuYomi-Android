# 時刻読み (Jikoku Yomi) for Android

決まった間隔で、いまの時刻を声で読み上げる時報アプリです。
(iOS版 "Jikoku - 時刻読み" の Android 版。ライセンスは MIT)

A time-signal app that speaks the current time aloud at set intervals.

## できること

- 読み上げ間隔: 15分 / 30分 / 1時間
- 鳴らす時間帯(開始・終了)を設定
- 時刻ごとに ON/OFF、話者、セリフを個別に設定(時ごとに折りたたみ表示)
- セリフは `{時}` `{分}` が使えます。例: `朝だよ!{時}時だよ`
- 声は「端末の音声合成(TTS)」か「ボイスパック(自分の音声ファイル)」から選べます
- 日本語 / 英語の読み上げ
- 端末を再起動しても動きます(正確なアラームを使用)

アカウント、サーバー、広告、解析はありません。データは外に送りません。

## 動作環境

Android 8.0 (API 26) 以上

## インストール

1. [Releases](../../releases) の APK を端末に入れる(なければ下の手順でビルド)
2. 「提供元不明のアプリ」を許可してインストール
3. 通知の許可を「許可」
4. アプリ内の「バッテリー最適化を無効化する」を押す(時刻どおりに鳴らすために必要)

### adb で入れる場合

```bash
adb install -r app-debug.apk
```

## ビルド

JDK 17 と Android SDK が必要です。

```bash
./gradlew assembleDebug
# 出力: app/build/outputs/apk/debug/app-debug.apk
```

Android Studio で開いてもビルドできます。

## ボイスパック(声の設定)

自分の音声ファイルを入れたフォルダを、アプリの「新しいボイスパックを取り込む」で選びます。
フォルダの中にサブフォルダがあっても読み込みます。

### ファイル形式

`wav` / `mp3` / `m4a` / `aac` / `flac` / `ogg`

### ファイル名

| ファイル名 | 読み上げる内容 |
|---|---|
| `tHHMM` (例: `t0715.wav`) | 「HH時MM分」を丸ごと読む音声 |
| `m15` `m30` `m45` | 分だけ読む音声(「時の省略」を使うとき) |

- `HH` は `00`〜`23`、`MM` は `00` `15` `30` `45` です。
- 15分間隔で全部そろえると、`t0000`〜`t2345` の96ファイルと `m15` `m30` `m45` の3ファイルです。
- 全部そろえなくても使えます。ファイルがない時刻は、端末の音声合成(TTS)で読みます。
- `t0715.wav` のように、拡張子の前の名前は小文字にします。

### pack.json(なくても可)

パックの名前を決められます。なければフォルダ名になります。

```json
{ "name": "マイボイス" }
```

### 例

```
my_pack/
├── pack.json
├── t0000.wav
├── t0015.wav
├── ...
├── t2345.wav
├── m15.wav
├── m30.wav
└── m45.wav
```

## VOICEVOX でパックを作る

[VOICEVOX](https://voicevox.hiroshiba.jp/) を起動して(`http://127.0.0.1:50021`)、付属のスクリプトで作れます。

```bash
python3 tools/make_voicevox_pack.py --list                       # 話者(speaker)の一覧
python3 tools/make_voicevox_pack.py --speaker 3 --out ./my_pack  # 例: ずんだもん(ノーマル)
```

できたフォルダを端末に送って、アプリで取り込みます。

VOICEVOX の音声には、キャラクターごとの利用規約とクレジット表記の決まりがあります。
作った音声を配るときは、各キャラクターの規約を確認してください。
このリポジトリには、音声ファイルは含まれていません。
